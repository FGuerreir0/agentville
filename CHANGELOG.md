# Changelog

## 0.1.0 (unreleased)

First release, coming soon.

- A live 3D city of your workspace: folders become districts, files become buildings.
- Claude and its subagents as orbs that walk the streets to read, edit, search, run commands
  and reach the web, with four landmarks: HQ, the bank, the radar and the launch site.
- Built-in chat running your installed Claude Code: model, effort, permission mode, budget,
  history, and permission cards with diffs.
- Metrics for every run, context window and plan usage bars, limit warnings.
- Explorer side bar view, as a minimap without the chat.
- Claude Code plugin installed and updated from the extension.
